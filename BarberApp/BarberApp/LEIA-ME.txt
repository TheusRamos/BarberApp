BARBERAPP - NODE.JS + POSTGRESQL

O backend está em backend/, na raiz do repositório.
Consulte backend/README.md para instruções completas.

1. Crie o banco barberapp no PostgreSQL.
2. Na raiz do repositório, execute npm install.
3. Copie .env.example para .env e preencha DATABASE_URL.
4. Execute npm run db:migrate.
5. Preencha ADMIN_* no .env e execute npm run admin:create.
6. Execute npm start e abra http://127.0.0.1:3000.

No PowerShell com scripts bloqueados, use npm.cmd em vez de npm.
Cadastre serviços e profissionais no painel antes de agendar.
O site deve ser aberto pelo servidor Node.js. GitHub Pages hospeda apenas
arquivos estáticos; para hospedagem separada, ajuste js/config.js e CORS_ORIGIN.
Nunca coloque credenciais do PostgreSQL no frontend.
